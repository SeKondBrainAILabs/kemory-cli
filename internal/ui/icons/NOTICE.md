# Client icons

Each icon is a client's mark in white on the client's brand colour, cut to a
64px rounded tile. The marks are their owners' trademarks, shown only to name
the client `kemory connect` connects.

- Claude Code, Claude, Codex, Cursor, Gemini CLI, Antigravity, Windsurf,
  Cline, Kiro, Grok and OpenCode: [Lobe Icons](https://github.com/lobehub/lobe-icons)
  1.95.1, MIT licence (below).
- GitHub Copilot (shown for VS Code) and Warp: [Simple Icons](https://github.com/simple-icons/simple-icons)
  16.35.0, CC0 1.0.
- Continue: a plain hexagon, drawn for kemory.
- `sekondbrain.png`: the SeKondBrain mark.
